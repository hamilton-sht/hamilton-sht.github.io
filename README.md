# Haoting Shi — Personal website

https://hamilton-sht.github.io/

A responsive, bilingual personal website built with HTML, CSS, and JavaScript.

- `index.html`: English content and Chinese translations (`data-zh`).
- `style.css`: layout and responsive styles.
- `script.js`: language switching.

Preview: `python3 -m http.server 8765`

GitHub Pages publishes the root of the `main` branch.
